# NORTHMINE public demo

Carpeta limpia para publicar una demo comercial de NORTHMINE en Seenode.

Incluye:
- `frontend/`: React/Vite.
- `backend/`: FastAPI en modo demo sintetico.
- `README_SEENODE_PUBLIC_DEMO.md`: pasos exactos para crear los servicios en Seenode.

No incluye bases SQLite locales, llaves locales, logs, pids, `node_modules`, `dist`, `.venv` ni datos runtime del equipo.
